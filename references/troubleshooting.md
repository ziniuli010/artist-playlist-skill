# 排查手册

## 1. 搜不到歌手 / 匹配到了错的人

**现象**：`没搜到歌手：XXX`，或输出目录名是另一个歌手。

**原因**：曲库存在同名艺人、粉丝团号、AI 翻唱号（如「周杰伦♚」「薛之谦后援会」）。

**处理**：

- 用更完整的名字搜索，如 `G.E.M.邓紫棋` 而不是 `邓紫棋`
- 英文歌手注意大小写与空格：`BIGBANG` 而非 `Big Bang`（脚本会自动匹配，但精确名命中率更高）
- 检查控制台第一行打印的 `→ <官方名> (id=...)` 是否为目标艺人

**判定技巧**：正规艺人账号的 `musicSize` 通常远大于 `albumSize`（数百至数千首），粉丝号往往只有几十首。

---

## 2. 整张专辑 0 首

**现象**：`[12/40] 2019-12-23 H3M (Remastered 2019) (0/10)`

**两种原因，看「无曲目入选的专辑」章节的标注：**

| 标注 | 含义 | 处理 |
|---|---|---|
| 曲目与更早专辑重复 | 该专辑是重制版/再版/精选，歌已在前面的专辑收过 | 正常，无需处理；想保留用 `--no-dedupe` |
| 整张非本人演唱 | 合作合辑，演唱者不是本歌手 | 正常；想保留用 `--include-featured` |

---

## 3. 想要原声带但被排除了

**现象**：电影原声带没进歌单。

**检查**：

1. 专辑名是否含 `原声带特辑`——该词在黑名单里，会整张跳过。用 `--exclude` 去掉这个词。
2. 专辑类型是否为 `专辑`——若被标为 `Single`/`EP`，需加 `--types 专辑,EP`。

```bash
python3 scripts/build_discography.py "周杰伦" --exclude "演唱会,精选,合辑"
```

---

## 4. 正式专辑被混音版挤成空专辑

**现象**：正式版 0 首，早期 `Rough Mix` / `Remastered` 版反而有歌。

**原因**：混音版发行日期早于正式版，先占位。

**处理**：本 skill 已用 D3「两轮抓取」处理，正常情况下不会发生。若仍出现：

- 确认专辑名中的修饰词在 `BAD_VER` 列表中（`remaster/deluxe/edited/rough mix/expanded/bonus/special edition/anniversary/重制/纪念版`）
- 若修饰词不在列表（如 `Pre-Release`），需在脚本 `BAD_VER` 中补充

---

## 5. 同一专辑出现两次（同名不同曲目数）

**现象**：控制台出现两条同名专辑，曲目数不同。

**原因**：曲库对同专辑重复上架（常见于 Deluxe 版）。

**处理**：D1 已按「归一化名 + 曲目数最多」合并，正常不会输出两次。若仍出现，说明两个名字归一化后不同（如一个带 `(Deluxe Edition)` 而 `Edition` 未在归一化规则里），需扩展 `norm_album()`。

---

## 6. 导入平台后匹配率低

**现象**：导入 QQ 音乐/网易云后大量「未匹配」。

**原因与对策**：

| 原因 | 对策 |
|---|---|
| 目标平台无版权 | 无法解决，属平台曲库差异 |
| 曲名版本后缀不一致（`(Live)` / `- Remastered`） | 导入前在清单里去掉后缀再试 |
| 合唱曲歌手名顺序不同 | 用 `--singers primary` 只写首位歌手 |
| 译名差异（中文歌手的外语专辑） | 人工核对，保留平台内的写法 |
| 单次粘贴过多超时 | 分批粘贴，每批 50–80 首 |

---

## 7. 请求失败 / 超时

**现象**：`请求失败: https://...` 或大量 `! 跳过《XX》`。

**处理**：

1. 检查网络能否访问 `music.163.com`
2. 降低并发：不要同时跑超过 4 个歌手
3. 调大脚本内 `time.sleep()` 间隔（默认 0.3s）
4. 重跑即可——已生成的歌手目录可单独重跑，不影响其他歌手

---

## 8. 输出为空

**现象**：`没有抓到曲目`。

**排查顺序**：

1. 控制台 `入选 N 张` 是否为 0 → 类型/关键词过滤太严，试 `--types all --keep-all`
2. 专辑 `size` 是否全为 0 → 曲库异常，稍后重试
3. 是否误传了翻唱号 id

---

## 9. 中文文件名在 Windows 上乱码

- 输出统一 UTF-8。Windows 记事本打开 CSV 用 `UTF-8 with BOM`（脚本已对 CSV 加 BOM）。
- `.md` 与 `.txt` 为无 BOM UTF-8，导入平台前不要用记事本另存为 ANSI。
